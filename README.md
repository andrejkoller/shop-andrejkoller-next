# shop andrejkoller

Personal shop website. Built with Next.js, TypeScript, and Tailwind CSS.

## Stack

- [Next.js 16](https://nextjs.org) (App Router)
- React 19
- TypeScript
- Tailwind CSS v4
- [Remix Icon](https://github.com/Remix-Design/RemixIcon)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
